# Security policy

## Supported versions

Mobile Spec Brain is pre-release. Security fixes are applied to the current default branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting flow for this repository. If that option is unavailable, contact the repository organization through its GitHub profile and include a minimal reproduction, impact, and any relevant version or commit.

Avoid attaching production source exports, access tokens, or personal data. We will acknowledge a report, assess the impact, and coordinate a fix before public disclosure where appropriate.
